# UnitFlow 🔄
### Every conversion. One simple place.

UnitFlow is a free, fast, and responsive all-in-one unit converter that makes everyday calculations simple. Convert between different measurement units instantly with a clean and user-friendly interface.

Whether you need to convert distance, weight, temperature, storage, or internet speed, UnitFlow brings everything together in one place.

## ✨ Features

- **9 Conversion Tools** – Convert length, weight, temperature, area, volume, speed, time, digital storage, and data transfer speed.
- **Instant Conversion** – Get results automatically as you enter a value.
- **Unit Swapping** – Quickly switch between source and target units.
- **Popular Conversions** – Access commonly used conversions with preselected units.
- **Search & Filters** – Find converters easily using search and category filters.
- **Favorites** – Save your frequently used conversion tools.
- **Recent History** – Automatically saves your recent conversions.
- **Copy Results** – Copy conversion results with one click.
- **Conversion Reference Table** – View equivalent values across available units.
- **Responsive Design** – Works smoothly on desktop, tablet, and mobile devices.
- **Smooth Animations** – Enjoy polished page transitions and interactive elements.
- **Local Storage** – Keeps favorites and conversion history saved in your browser.

## 🧮 Available Converters

| Converter | Supported Units |
|---|---|
| Length | km, m, cm, mm, µm, nm, miles, yards, feet, inches |
| Weight | Tonnes, kg, g, mg, µg, pounds, ounces |
| Temperature | Celsius, Fahrenheit, Kelvin |
| Area | km², hectares, acres, m², cm², ft², yd², mi² |
| Volume | m³, liters, milliliters, gallons, quarts, pints, cups |
| Speed | m/s, km/h, mph, ft/s, knots |
| Time | ns, µs, ms, seconds, minutes, hours, days, weeks |
| Digital Storage | Bits, bytes, KB, MB, GB, TB, KiB, MiB, GiB, TiB |
| Data Transfer | bit/s, kbit/s, Mbit/s, Gbit/s, B/s, KB/s, MB/s, GB/s |

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- LocalStorage API
- Google Fonts (Inter)

## 📱 Responsive Design

UnitFlow is designed with a mobile-first approach to provide a consistent experience across different screen sizes.

## 💾 Data Storage

UnitFlow uses your browser's LocalStorage to save:

- Favorite conversion tools
- Recent conversion history

No account or registration is required. Your saved data stays in your browser.
